# The Brillantes Bill Tracker System

A simple household bill tracker for managing monthly due dates, payments, and outstanding balances.

## GitHub repository

This project is linked to the GitHub repository: https://github.com/rhogen777-commits/My-First-Project

## Start the app on Windows

1. Install Node.js from https://nodejs.org/ if it is not installed.
2. Double-click `start.bat`.
3. Open http://localhost:3000 if the browser does not open automatically.

You can also run `npm start` from this folder.

## GitHub setup steps

1. Create a new repository on GitHub.
2. Run the following commands in this project folder:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/rhogen777-commits/My-First-Project.git
git push -u origin main
```

## Features

- Monthly billing overview
- Mark bills as paid or unpaid
- Edit and delete entries
- Local browser storage for saved data
- Simple PWA-style install support
